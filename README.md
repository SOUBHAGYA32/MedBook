# 📚 MedBook

**MedBook** is a clean and user-friendly iOS/iPadOS application that allows users to search for books, bookmark them for future reference, and securely manage user authentication.

---

## ✨ Features

- 🔍 **Book Search** using the Open Library API
- 📌 **Bookmark System** with persistent storage using Core Data
- ✅ **User Authentication** (SignUp/Login) using Core Data
- 📬 **Toast Messages** using `Toast-Swift`
- ⚡ **Search Debouncing** (starts after 3+ characters)
- 📱 Optimized for iPhone and iPad

---

## 🛠 Tech Stack

- **Language:** Swift
- **UI Framework:** UIKit
- **Database:** Core Data
- **Networking:** Alamofire
- **Other Libraries:**
  - [Toast-Swift](https://github.com/scalessec/Toast-Swift)
  - [ProgressHUD](https://github.com/relatedcode/ProgressHUD)
